Parte C

Publicar o projeto de vocês

C1 — Criar repo vazio

C1

ONDE GitHub logado

  1. Canto superior direito: +
  2. New repository
  3. Name: inss-fiap- + vosso nome
  4. NÃO marcar README
  5. Botão verde Create repository
Colem usuário + nome do repo em Minhas URLs

C2a — Conferir o Git

C2a

DIGITAM no PowerShell

git --version

APARECE git version 2....

Não reconhecido? Instalem o Git (git-scm.com) ou usem GitHub Desktop.

C2b — Enviar o código

C2b

DIGITAM um de cada vez (troquem a URL!)

cd C:\fiap-aluno
git init
git add .
git commit -m "INSS FIAP aluno"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/inss-fiap-SEU_NOME.git
git push -u origin main

C2c — Conferir no browser

C2c

ATUALIZEM a página do repo no GitHub

APARECE pastas projeto e docs

Se as pastas não aparecerem, o push não concluiu — refaçam o C2b

C3a — Neon: criar projeto

C3a

ONDE console.neon.tech

  1. Create project · nome inss-aula
  2. Create
  3. Abram Connect / Connection string
  4. Copiem a string postgresql://... → Bloco de Notas

C3b — Neon: 2º database

C3b

ONDE SQL Editor no Neon

DIGITAM e Run:

CREATE DATABASE inss_beneficios;

APARECE sucesso

C3c — Montar 2 connection strings

C3c

No Bloco de Notas, 2 linhas (mesmo host/senha · Database diferente):

Host=....neon.tech;Database=neondb;Username=...;Password=...;SSL Mode=Require;Trust Server Certificate=true

Host=....neon.tech;Database=inss_beneficios;Username=...;Password=...;SSL Mode=Require;Trust Server Certificate=true
String 1 = Contribuintes · String 2 = Benefícios

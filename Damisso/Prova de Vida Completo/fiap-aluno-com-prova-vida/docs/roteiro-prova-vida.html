0 — Conceito da turma (o desenho)

No rascunho, o FRONT fala com CONTRIBUINTE e BENEFÍCIOS. A Prova de Vida é outro fluxo: o MOBILE alimenta DADOS BIOMÉTRICOS e PROVA DE VIDA, ligados ao contribuinte pelo GUID.

0b — Mapa: caixa do desenho → o que foi implementado

No desenho / PDF da turma Já existia? (sem PV) O que implementamos a mais
FRONT Sim — portal React :5173 Continua (aula de PV não exige). Webcam em :5180 é front extra de demo.
CONTRIBUINTE Sim — API :5001 + perfil Pensionista · endpoints /pensionistas · seed NUIT 30040050x
BENEFÍCIOS Sim — API :5002 Sem mudança obrigatória para PV (fica no desenho completo do sistema).
DADOS BIOMÉTRICOS ← seta GUID Não NOVO PerfilBiometrico · embedding 128D · ponte por GUID (sem JOIN entre bancos) · não grava foto

MOBILE (círculos) Não NOVO projeto/app-mobile · APK Expo · liveness 3 poses · (alternativa: webcam no PC)
Em uma frase: o papel da turma pediu biométrica + prova de vida + mobile ligados por GUID; o código entregou exatamente isso em cima do FRONT/CONTRIBUINTE/BENEFÍCIOS que já existiam.

B — Passo a passo do que foi implementado

Ordem real da construção da feature (não é só “como ligar” — é o que o código ganhou).

I1 Perfil Pensionista em Contribuintes

  • Enum PerfilContribuinte (ex.: Pensionista)
  • Endpoint /api/contribuintes/pensionistas e .../por-nuit/{nuit}
  • Seed com NUITs 300400501…300400504
  • Migration AddPerfilContribuinte

POR QUÊ Prova de Vida é só para aposentados/pensionistas — NUIT de trabalhador deve falhar.

I2 Microsserviço ProvaVida (camadas)

Projetos novos em projeto\api\src\:

  • ProvaVida.Api — controllers, CORS, porta :5003
  • ProvaVida.Application — serviços, DTOs, mapper
  • ProvaVida.Domain — entidades, enums, regras
  • ProvaVida.Infrastructure — EF Core, repositórios, HttpClient → :5001
docker/postgres-init → cria também inss_prova_vida
dotnet ef migrations → InitialCreate + PerfilBiometrico + FaceEmbedding

I3 Domínio: identidade sem gravar foto

  • PerfilBiometrico — ContribuinteId (GUID) + NUIT + FaceEmbeddingJson
  • RegistroProvaVida — histórico + status + validade
  • ComparadorFacial — similaridade cosseno · limiar ≥ 72%
  • ValidadeProvaVida — 12 meses
